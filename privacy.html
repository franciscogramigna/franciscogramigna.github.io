Política de Privacidad de IVS

Última actualización: 28 de septiembre de 2026.

1. Alcance

IVS es un sistema de uso personal y privado, operado por y para una única persona: su propietario. No es un servicio ofrecido al público y no tiene otros usuarios.

2. Qué datos accede IVS

Con autorización expresa del propietario de la cuenta, IVS accede únicamente a la cuenta de Google del propio propietario, y solo a lo necesario para su funcionamiento: correo electrónico y calendario.

3. Cómo usa esos datos

Los datos se usan exclusivamente para organizar y automatizar la información del propio propietario. No se usan para publicidad ni para ningún fin comercial.

4. Dónde se guardan

El procesamiento y el almacenamiento ocurren localmente, en los equipos del propietario. No hay servidores de terceros que reciban esta información.

5. Con quién se comparten

Con nadie. No se venden, alquilan, ceden ni comparten datos con terceros. No se transfieren a ninguna otra organización.

6. Uso de las API de Google

El uso que IVS hace de la información recibida de las API de Google se ajusta a la Política de datos de usuario de los servicios de API de Google, incluidos sus requisitos de uso limitado.

7. Retención y borrado

Los datos permanecen en los equipos del propietario mientras este los conserve. El propietario puede revocar el acceso de IVS en cualquier momento desde su cuenta de Google y eliminar los datos locales borrándolos de su equipo.
